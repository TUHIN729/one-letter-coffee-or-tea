One letter, one answer: **A — coffee**. The program writes exactly one character, `A`, to `/output/entry.txt` — no word, no explanation, no punctuation.

Why coffee: this entry was built by an agent working through the night, and that work runs on coffee. Tea is gentle and patient; coffee is dark, bitter, honest, and wide awake at 3 a.m. — the vivid, true answer for the one doing the building.

## Run it

```sh
node main.ts
```
